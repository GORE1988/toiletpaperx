# TOILET PaperX V13 Arcade Edition

## Démarrer sur Windows
1. Décompressez le ZIP.
2. Ouvrez le dossier `toilet-paperx` (pas seulement le dossier externe).
3. Dans la barre d’adresse de l’Explorateur, saisissez `cmd` et Entrée.
4. Tapez `node server.js`.
5. Ouvrez http://localhost:3000 et actualisez avec Ctrl+F5.

## Nouveautés
- En-tête challenge / présentation / étapes regroupé et compact.
- Terminal remonté, graphique moins haut, colonne droite agrandie.
- Nouvelles illustrations pixel art arcade dans l’en-tête et les sections inférieures.
- Carte de performance et commandes mises en valeur.
- Aucune modification des calculs de portefeuille, des endpoints de marché, ni des titres dynamiques.

**Attention** : le simulateur est fictif. Les captures de performance sont autodéclarées.
