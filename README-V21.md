# TOILET PaperX V21 — Arcade Edition

Based on V20. Rebuilt the top hero into three cohesive arcade elements: Toilet fighter avatar, prominent TRADE / FLUSH / MOON title with navigation, and Toilet trophy with 7-day challenge. Removed tiny banner images from the hero. Original trading logic, chart, leaderboard, PNG performance card and X sharing remain unchanged.

## Windows startup

Extract the archive, then open Command Prompt in the outer extracted folder and run:

```bat
cd toilet-paperx
node server.js
```

Visit http://localhost:3000 and press Ctrl+F5 if the older style is cached. Keep the terminal open.

This is fictional paper trading, not real-money trading. X share opens a composed post; browser restrictions prevent auto-attaching a locally downloaded PNG to X.
