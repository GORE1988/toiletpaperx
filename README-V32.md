# Toilet PaperX V32 — Vice Scene Variety

Based on V31 Vice Immersive. Eight distinct Vice City-inspired illustrations replace the eight vice-* image assets, featuring different scenes and the Toilet mascot. The trading logic, Node server, layout and audio are retained. Browser cache-busting query strings were added.

## Run on Windows
1. Extract the ZIP.
2. Open Command Prompt in the extracted `toilet-paperx` subfolder (the one containing `server.js`).
3. Run `node server.js`.
4. Open the local URL printed in the terminal, or consult README.md.

This is a fictional paper trading simulator, not a real exchange.
